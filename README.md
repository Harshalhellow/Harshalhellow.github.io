# Harshal Mishra — Portfolio

A lightweight static portfolio showcasing my software-development experience,
machine-learning research, selected projects and technical writing.

## Local preview

From the repository root, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Structure

- `index.html` — introduction, selected work, experience and skills
- `projects.html` — personal software projects
- `writings.html` — reports and research
- `resume.html` — embedded and downloadable résumé
- `styles.css` — shared responsive design system
